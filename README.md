# Школа глазами учеников — школа № 534

Ученический исследовательский проект: адаптивный сайт с результатами опроса и схематичной объёмной моделью школы.

## Возможности

- Четыре этажа учебной части и двухэтажная пристройка, выбор этажей, раздвижение уровней, вращение и прогулка по зонам.
- Опрос через Google Forms, встроенный на страницу и доступный по отдельной ссылке.
- Автоматическое обновление обезличенной статистики из Google Apps Script и резервная сводка для показа без интернета.
- Диаграммы, фильтр групп классов, резервный импорт CSV и выгрузка сводных результатов.

Модель и расположение внутренних помещений условные. Это не архитектурный чертёж, не план эвакуации и не официальный сайт школы. Результаты отражают мнения участников опроса, а не обязательно всей школы.

## Локальный просмотр

Открыть `dist/index.html` в обычном браузере. Установка зависимостей и сборка не нужны. Для формы, карты, внешней фотографии и обновления опроса нужен интернет; сама модель и резервные результаты доступны без него.

## Публикация на Vercel

Импортировать этот репозиторий в Vercel. Корень проекта — корень репозитория, Framework Preset — Other. Настройки в `vercel.json` отключают установку зависимостей и сборку, а публикуемая папка — `dist`.

После привязки репозитория последующие изменения в основной ветке должны запускать публикацию через интеграцию Vercel с GitHub.

## Обновление данных

Адрес опубликованного агрегатора задан в `dist/sync-config.js`. Это публичный адрес обезличенной сводки, а не пароль или OAuth-токен. При исправном подключении статистика запрашивается раз в минуту в видимой вкладке. Индивидуальные анкеты и тексты предложений не запрашиваются через этот адрес.

`initial-data.js` содержит резервный срез, который обновляется отдельно. Ошибка связи не удаляет показанную сводку. При резервном импорте CSV его данные временно имеют приоритет; для возврата к Google используется кнопка в разделе автора.

## Исходники

- `dist/index.html`, `style.css`, `app.js` — страница и интерфейс.
- `dist/model-data.js`, `model.js`, `model.css` — описание зон и модель.
- `dist/data.js` — обработка ответов и подсчёты.
- `dist/sync.js`, `sync-config.js`, `initial-data.js` — связь с Google и резервная статистика.

Исходные CSV, архивы ответов, личные настройки и локальные рабочие заметки исключены из репозитория и публикации.
